一、新增方法（两个文件都加）

1. _log_dirty_sample(sig, transaction, meta)
位置：
trade_stream.py：紧跟 _resolve_trader_owner 之后
trade_backfill.py：紧跟 _decode_instruction_type 之前
作用：当一条 tx 被 BUY/SELL 闸门判定为"非买卖"而丢弃时，把 main ix 和 inner ix 里所有非 dict 元素的形状打印出来 + logMessages 头 6 条。
为什么：让你看到被丢弃的脏样本到底长啥样，如果脏样本里有买卖信息，可以反推闸门放宽。
性能：仅在"被丢弃"时调用，每条 ≤100μs。
2. _resolve_trader_owner(pre, post, mint, fallback_signer) → (owner, pre_amt, post_amt)
位置：同 _log_dirty_sample

作用：从 meta.preTokenBalances / postTokenBalances 里找"动了本 mint 的 owner"，找不到回退 signer。
为什么：pump.fun V0+ALT 场景，fee-payer 可能是 Jito tip payer / bot router，不是真实 trader。
性能：双列表遍历，<20μs/tx。

作用：

修复：原代码 SELL 错误返回负值（原符号反），BUY 把 jito tip 重复扣除。

4.4 amount overflow 保护
try:
    if abs(delta) > 1e15:
        logger.warning(f"amount 超出安全范围 sig={sig[:8]} delta={delta:.4e}")
        amount = 0.0

except (TypeError, ValueError):

作用：Solana u64 token 理论最大可达 1.8e19，转 float 会丢失精度。超出 1e15（千万亿级别）视为异常，记 warning，置 0 防止下游指数计算炸掉。

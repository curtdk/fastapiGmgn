成功后transactionSubscribe，服务器会在该字段中返回一个订阅 ID 。该 ID 与来自该订阅的每条通知中result显示的编号相同：params.subscription

订阅回复

通知

{
  "jsonrpc": "2.0",
  "method": "transactionNotification",
  "params": {
    "subscription": 4743323479349712,
    "result": {}
  }
}

订阅回复
{
  "jsonrpc": "2.0",
  "result": 4743323479349712,
  "id": 420
}
保存响应中的订阅 ID。您需要它来取消订阅。
​
取消订阅
要停止接收通知，请transactionUnsubscribe使用订阅 ID 调用服务。transactionSubscribe同一连接上的每次调用都会创建一个具有各自 ID 的独立订阅，因此请务必在重新订阅之前取消订阅，以免收到重复通知。

 

取消订阅
{
  "jsonrpc": "2.0",
  "id": 421,
  "method": "transactionUnsubscribe",
  "params": [4743323479349712]
}
回复
{
  "jsonrpc": "2.0",
  "result": true,
  "id": 421
}

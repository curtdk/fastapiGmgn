## 10. 启动时数据来源（不同于实时）

| 数据 | 启动时来源 | API |
|------|------------|-----|
| 用户表 | `fetchUsers()` | `GET /admin/api/users?mint=...` |
| 簇组卡 | **无** | 缺（需调用 `/admin/api/clusters/summary`）|
| 交易表 | 无 | 缺（依赖实时或 backfill_done 推送）|
| 指标 | 无 | 依赖实时或 backfill_done 推送 |

**结论**：启动后通过 `fetchUsers()` 填用户表，但**簇组卡启动时为空**，直到第一笔实时交易触发 `user_status` → `computeClusterSummary`。

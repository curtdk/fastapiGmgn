# /trade 页面 — 用户列表数据流程

## 一、概述

`/trade` 页面用户列表由**两条路径**协作驱动：

1. **初始加载**：`startMonitor()` 时调用 `GET /admin/api/users` 一次性获取
2. **实时更新**：每笔交易处理完毕后，`_calculate_index()` 广播 `user_status` WS 消息，前端增量更新

前端维护 `userData` 对象（`{address: {...}}`），两路径共用同一数据结构，WS 推送直接覆盖/新增。

---

## 二、初始加载 — `GET /admin/api/users?mint=xxx`

### 位置

[`app/routes/trades.py`](../app/routes/trades.py) — `api_get_users()`

### 获取逻辑

```
SCAN user:{mint}:* 遍历当前 mint 的所有用户持仓 key
  → 对每个 user:{mint}:{address} 执行 hgetall 获取持仓数据
  → 再读 user:{address} 获取全局信息（status / cluster_name）
  → 返回
```

### 性能优势

原来扫描 `user:*` 全量 key 再逐条检查是否有 `{mint}_` 前缀，现在直接扫描 `user:{mint}:*` 只命中当前 mint 用户，O(n) 变 O(m)（m 远小于 n）。

### 返回字段

| 字段 | 来源 | 说明 |
|------|------|------|
| `address` | key 去掉 `user:{mint}:` 前缀 | 钱包地址 |
| `status` | `user:{address}.status` | dealer / retail / unknown |
| `status_source` | `user:{address}.status_source` | system / manual |
| `conditions` | `user:{address}.conditions` | 判定条件列表 JSON |
| `cluster_name` | `user:{address}.cluster_name` | 所属簇组名称 |
| `cluster_type` | 从簇组 Redis 实时读取 | 最新簇组类型 |
| `cluster_tx_count` | — | 已弃用，固定为 0 |
| `cluster_user_count` | — | 已弃用，固定为 0 |
| `holding_qty` | `user:{mint}:{address}.holdingQty` | 当前持仓数量 |
| `holding_cost` | `user:{mint}:{address}.holdingCost` | 当前持仓成本(SOL) |

### 前端调用

[`app/templates/trade_live.html`](../app/templates/trade_live.html)

```javascript
async function fetchUsers() {
  const resp = await fetch('/admin/api/users?mint=' + currentMint);
  const data = await resp.json();
  userData = {};
  data.users.forEach(function(u) { userData[u.address] = u; });
  renderUserTable();
}
```

## 三、实时更新 — WS `user_status` 推送

### 位置

[`app/services/trade_processor.py`](../app/services/trade_processor.py) 的 `_calculate_index()` 方法末尾。

### 广播内容

```python
await ws_manager.broadcast(mint, {
    "type": "user_status",
    "data": {
        "address": address,
        "status": state["status"],
        "status_source": state.get("status_source", "system"),
        "conditions": state.get("conditions", []),
        "cluster_name": cluster_name,
        "cluster_type": cluster_type,
        "cluster_tx_count": 0,     # 已弃用
        "cluster_user_count": 0,   # 已弃用
        "holding_qty": holding_qty,
        "holding_cost": holding_cost,
    }
})
```

### 前端接收

```javascript
function handleUserStatus(data) {
  // 1. 更新交易表格中对应行的状态
  // 2. 更新用户列表
  upsertUserRow(data);
}

function upsertUserRow(data) {
  userData[data.address] = data;   // 覆盖或新增
  renderUserTable();               // 重新渲染 + 自动调 computeClusterSummary()
}
```

## 四、完整时序流程

```
用户点击"开始"
  │
  ├─ startMonitor()
  │   ├─ fetchUsers()           ← 一次性拉全量用户（SCAN user:{mint}:*）
  │   │   └─ renderUserTable()
  │   │       └─ computeClusterSummary()  ← 自动计算簇组概览
  │   │
  │   └─ connectWS()            ← 建立 WebSocket
  │
  ▼
每笔 tx 到达
  │
  ├─ _calculate_index()
  │   ├─ get_trader_state_with_sig()  ← C002-C008 判定（合并两个 key 读取）
  │   ├─ BUY/SELL 计算（庄家/散户共用）
  │   ├─ save_trader_state()          ← 写入两个 key
  │   │   ├─ user:{address}           ← 全局信息
  │   │   └─ user:{mint}:{address}    ← per-mint 持仓
  │   └─ ws_manager.broadcast("user_status", {...})  ← 推送
  │
  ▼
前端 WS onmessage
  │
  ├─ msg.type === "user_status"
  │   ├─ handleUserStatus()
  │   │   ├─ 更新交易表格行
  │   │   └─ upsertUserRow()
  │   │       └─ renderUserTable()
  │   │           └─ computeClusterSummary()  ← 同步刷新簇组概览
```

## 五、两条路径对比

| | 初始加载 | 实时更新 |
|------|----------|----------|
| 触发方式 | `startMonitor()` | 每笔 tx 的 `_calculate_index()` |
| 传输方式 | HTTP `GET` | WebSocket `user_status` |
| 扫描范围 | `SCAN user:{mint}:*` | 无额外查询，直接推送 |
| 数据范围 | 当前 mint 全量用户 | 单用户 |
| 前端操作 | 覆盖整个 `userData` | 覆盖/新增单个 `userData[address]` |

## 六、关键 Redis 数据

```
user:{address}                      # Hash — 全局信息（跨 mint 共享）
  ├─ status: "dealer" / "retail" / "unknown"
  ├─ status_source: "system" / "manual"
  ├─ conditions: '["C006","C008"]'
  ├─ cluster_name: "GdZisw_BUY"
  └─ {mint}_dealerExcluded: "true"     ← per-mint 排除标记

user:{mint}:{address}               # Hash — per-mint 持仓
  ├─ holdingQty: "1000.5"
  ├─ holdingCost: "5.5"
  ├─ avgPrice: "0.0055"
  ├─ totalBuyAmount: "10.0"
  ├─ totalSellAmount: "3.0"
  └─ totalSellPrincipal: "2.5"

cluster:data:{name}                 # Hash — 匹配参数 + cluster_type
  ├─ cluster_type: "dealer" / "retail" / "undefined"
  ├─ judgment_type: "system" / "manual"
  ├─ base_cu / base_program_count / ...   ← 匹配参数
  └─ base_programs / base_main_instructions / ...
  (已移除: txs / users / tx_count / user_count)
```

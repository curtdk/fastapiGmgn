## 指数算法流程（标准版）

### 1. 三个指数定义

```
total_bet        本轮下注   = Σ holding_cost              (status ≠ dealer 的用户)
realized_profit  已落袋    = Σ (totalSellAmount - totalSellPrincipal)  (status ≠ dealer 的用户)
current_cost     本轮成本   = total_bet - realized_profit
total_holdingQty 全局持仓  = Σ holding_qty (含庄家，仅用于 C008 分母)
```

### 2. 单笔交易处理流程

```
每笔交易 (BUY/SELL):
  ① 庄家判定（C002-C006 统一入口）→ state.status
  ② 读 per-mint 持仓 (user:{mint}:{address})
  ③ 计算 BUY/SELL 本地 delta:
     BUY:  delta_bet = +buy_amount
     SELL: delta_bet = -sell_qty × avg_price
           delta_profit = sell_amount - sell_principal
  ④ 更新 per-mint 持仓 (holdingQty/Cost/avgPrice/totalSellAmount/Principal)
  ⑤ 写 user:{address}.status + dealerExcluded
  ⑥ 更新 total_holdingQty (含庄家)
  ⑦ 分支:
     - status = retail/unknown:
         total_bet       += delta_bet       (HINCRBYFLOAT)
         realized_profit += delta_profit    (HINCRBYFLOAT)
     - status = dealer (首次):
         _adjust_metrics_for_user(mint, addr, sign=-1)
         ← 自动从散户池移除该用户贡献
     - status = dealer (已排除):
         跳过，不动 total_bet / realized_profit
  ⑧ WS 广播 trade / cluster_matched / user_status
```

### 3. 用户状态切换流程（关键）

> **核心不变式**：任何时刻 `total_bet = Σ holding_cost (status ≠ dealer)`

#### 3.1 切换实现

所有切换统一通过 `_adjust_metrics_for_user(mint, address, sign)`：

| sign | 语义 | total_bet | realized_profit | dealer_count | dealerExcluded | status |
|------|------|-----------|-----------------|--------------|----------------|--------|
| -1   | retail → dealer | `-= holding_cost` | `-= user.realized` | `+1` | `= "true"` | `= "dealer"` |
| +1   | dealer → retail | `+= holding_cost` | `+= user.realized` | `-1` | `= ""`     | `= "retail"` |

**user.realized 现算**（A1 方案）：`user.realized = totalSellAmount - totalSellPrincipal`，不新增字段。

#### 3.2 三个调用入口

| 入口 | 触发时机 | sign |
|------|---------|------|
| `_calculate_index` 检测到首次 dealer | 每笔交易处理时 | -1 |
| `propagate_cluster_type_to_users` 改簇类型 | 手动改簇 dealer→其他 | +1 |
| `propagate_cluster_type_to_users` 改簇类型 | 手动改簇 其他→dealer | -1 |
